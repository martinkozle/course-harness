# Share code through the `course_harness.core` submodule

Course Harness and the Classroom share schema models, validation, Release reading and slide preview rendering through the `course_harness.core` submodule rather than a second Python distribution. Only `course-harness` is published to PyPI, so there is no extra package to version, release or keep compatible. `course_harness.core` imports only the standard library, its light dependencies (pydantic, pyyaml, python-pptx, pillow) and itself, and `course_harness/__init__.py` stays import-free; a test enforces this boundary. In development the Classroom imports core from the editable Harness install; its Docker image copies only `course_harness/__init__.py` and `course_harness/core/`, so docling and the agent stack never ship with it. The cost is a boundary kept by convention and a test rather than by packaging, which we accept while the Classroom is not itself published.
