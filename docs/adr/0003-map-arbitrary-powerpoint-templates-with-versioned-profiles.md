# Map arbitrary PowerPoint templates with versioned profiles

Import PowerPoint templates through a guided inspection that combines deterministic layout and placeholder metadata, heuristic or LLM-assisted semantic suggestions, and user correction, then save the result as a globally reusable Template Profile. Each Course pins a profile version so later mapping corrections do not silently alter existing output; this trades a small onboarding step for native editable decks across structurally usable templates without pretending arbitrary templates are self-describing.
