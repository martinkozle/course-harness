# Represent Course Releases with Git tags and manifests

Keep the working Course editable and publish immutable Course Releases as annotated Git tags over validated Course Revisions, accompanied by a manifest that pins Source Versions, the Template Profile version, validation results, and Artifact checksums. This makes academic/demo milestones recognizable and recoverable without pretending the mutable latest revision is a publication or relying on generated binaries as authoritative state.
