# Keep portable Course intent in human-readable files

Make a small YAML/Markdown tree authoritative for Course metadata, instructions, Sources, ordered Lectures, Presentations, notes, and Course-owned assets, with generated Artifacts kept reproducible rather than authoritative. Keep chat/runtime history, secrets, indexes, parser outputs, and shared Library objects outside canonical files; detect external edits as Workspace Drift and require validation or Course Author-reviewed agent Reconciliation before committing a Course Revision.
