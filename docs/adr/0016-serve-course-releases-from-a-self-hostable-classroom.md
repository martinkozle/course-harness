# Serve Course Releases read-only from a self-hostable Classroom

Learners use a separate, self-hostable Course Harness Classroom rather than Course Harness itself, which stays a local authoring tool. The Classroom pulls only from public HTTPS Git remotes an Administrator has attached, keeps a bare mirror, and reads the newest valid Course Release tag with `git show`: it never checks out or executes repository content and never serves the mutable working state. An invalid new Release is skipped and the previous one stays, and Learners always see the latest valid Release without choosing a version. Access uses per-course Share Links for Learners and Instructors instead of accounts; each token is exchanged for an HttpOnly cookie, and rotating a link invalidates the old one. Learner identity is a self-declared name and student ID, which is trust-based but enough for a classroom without login. The Classroom hosts Lectures, Quizzes, Citations and the Release's PPTX, but no Source binaries, so publishing a Course never redistributes the material it cites.
