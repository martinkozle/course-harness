# Serve Course Releases read-only from a self-hostable Classroom

Learners use a separate, self-hostable Course Harness Classroom rather than Course Harness itself, which stays a local authoring tool. The Classroom pulls only from public HTTPS Git remotes an Administrator has attached, keeps a bare mirror, and reads the newest valid Course Release tag with `git show`: it never checks out or executes repository content and never serves the mutable working state. An invalid new Release is skipped and the previous one stays, and Learners always see the latest valid Release without choosing a version. Access uses per-course Share Links for Learners and Instructors instead of accounts; each token is exchanged for an HttpOnly cookie, and rotating a link invalidates the old one and the sessions opened with it. Share Link tokens are stored, not only their hashes, so a link can be shown and copied again: the links are meant to be shared, and reading the database already implies access to the server. Lookups still go by hash, and session IDs are stored only as hashes. A link created before tokens were stored keeps working but must be rotated to be shown again. An Administrator session is an Instructor of every course, so the Administrator needs no link. Instructors can rotate the Learner link, but only the Administrator rotates the Instructor link, so one Instructor cannot lock the others out; attaching and detaching courses stays with the Administrator. An Instructor can view a course as a Learner, which is only a display preference: the server keeps treating them as an Instructor, and their answers stay marked as an Instructor's. Learner identity is a self-declared name and student ID, which is trust-based but enough for a classroom without login. Instructors are not asked for one: their own tries go under a per-browser ID. The Classroom hosts Lectures, Quizzes, Citations and the Release's PPTX, but no Source binaries, so publishing a Course never redistributes the material it cites. The one exception is a picture the Course Author placed on an image Slide: the Release PPTX already embeds it, so the Classroom shows that embedded copy.
