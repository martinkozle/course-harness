# Search papers natively and the web through Connectors

Give the Course Agent two research paths. Paper search (arXiv, Crossref, Semantic Scholar, OpenAlex) stays native in `discovery.py`, because admission and Citation need structured Candidates with reliable DOI/arXiv identity, and the Sources canvas reuses the same providers. Web search goes through Connectors: remote MCP servers the Course Author configures per installation, with Exa pre-configured as an editable, deletable default so another search service such as Tavily can replace it without a special case in the product. Connector output is untrusted Candidate material: a URL may be added only if it appeared in a result earlier in the Conversation, and Citations always point to Evidence in a Snapshot that Course Harness captured itself (or, when direct capture fails, fetched through the Connector, recorded as such), never to search excerpts. Local stdio MCP servers are excluded until they have their own trust design, because they run arbitrary local commands.
