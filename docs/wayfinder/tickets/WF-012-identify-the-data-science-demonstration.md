# Identify the Data Science and Advanced Data Science demonstration

## Question

Which observable techniques, experiments, metrics, or design contributions should the working proof of concept demonstrate so one project credibly satisfies both master's subjects without requiring a separate academic report?

## Resolution

Present Course Harness as a polished working product demonstration rather than a quantitative
evaluation study. The demo should make source processing, retrieval, inspectable Evidence and
Citations, version pinning, template inference and correction, observable agent work, and editable
artifact generation visible through one coherent Course-authoring journey. No evaluation metrics
or separate academic report are required.
